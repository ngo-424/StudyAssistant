# 模块 01（1.1）界面基础验收记录

## 实现范围

- 1.1 使用嫩芽绿、暖白与柔和圆角的统一浅色/深色设计令牌。
- 一级导航统一显示“时芽”品牌与系统符号，移除工程名和开发口号。
- 紧凑手机窗口保留四个一级入口，不再强制停留在专注页。
- 新增统一操作按钮、状态提示、加载与空状态组件。
- “我的”建立概览和账号、专注设置、同步、数据与隐私详情入口。

## 自动化验收

- Debug/Release HAP 编译必须通过。
- 本地 ArkTS 测试源码必须编译通过。
- `WindowLayoutPolicy` 既有紧凑窗口规则保持通过，页面导航不再受该规则屏蔽。

## 手动验收

1. 手机竖屏确认四个底部入口均可进入。
2. 将窗口缩小到紧凑尺寸，确认导航仍可见且四页均能打开。
3. 深浅色模式确认文字、边框和按钮状态清晰。
4. “我的”所有入口均有明确返回路径，不出现无响应箭头。
