# 模块 6 真机与能力验收清单

模块 6 已在代码层接入智慧多窗、`TIMER` 实况窗、代理提醒和普通通知降级。实况窗与代理提醒均需在 AppGallery Connect 完成相应能力申请，并使用已签名的真机包验证；预览器和模拟器不能替代这部分验收。

## 提交能力申请前

1. 将开发代号包名 `com.example.studyassistant` 替换为最终永久包名。
2. 在 AppGallery Connect 中为应用申请实况窗与代理提醒能力。
3. 确认应用场景说明只描述专注/休息计时，不申请全局覆盖悬浮窗权限。
4. 配置调试或正式签名，安装到中国大陆地区的 HarmonyOS NEXT 手机和平板。

## 通知行为

1. 首次开始计时时允许通知：确认倒计时继续运行，并检查实况窗、代理提醒或普通通知的状态提示。
2. 首次开始计时时拒绝通知：确认计时仍正常开始，页面显示“通知未开启，将继续使用应用内计时”。
3. 在系统设置中关闭通知后再次进入：确认应用不崩溃、不重复弹窗，应用内计时仍可用。
4. 当实况窗或代理提醒能力未获批时：确认页面显示普通通知降级状态；通知内容不展示任务标题。
5. 暂停、继续、提前结束、放弃：确认系统提醒与页面状态同步，终止后无遗留通知或实况窗。
6. 结束应用进程后等待计时结束：能力获批时应收到代理提醒；未获批时属于已知降级场景。

## 窗口形态

1. 手机全屏：显示完整专注页和底部一级导航。
2. 平板全屏或分屏：宽屏时显示侧边一级导航，计时区域保持居中。
3. 浮动小窗：窗口宽小于 520vp 且高小于 640vp 时进入紧凑布局，仅保留计时核心与系统能力状态，隐藏一级导航和任务选择。
4. 从全屏连续切换到分屏、浮窗再恢复：确认当前计时、关联类别颜色、暂停状态均不丢失。
5. 旋转设备并调整分屏比例：确认没有按钮被截断，必要时页面可纵向滚动。

## 隐私与权限检查

- Manifest 仅新增 `ohos.permission.PUBLISH_AGENT_REMINDER`，没有全局覆盖悬浮窗权限。
- 锁屏、实况窗和普通通知只显示“已关联任务”或“自由专注”，不显示任务标题。
- 拒绝通知不影响任务、统计、本地数据和应用内计时。
