# 模块 9 邮箱验证码账号验收清单

## 已实现范围

- 客户端支持游客状态、申请邮箱验证码、验证码注册/登录、退出登录和账号注销。
- 游客任务、专注记录和积分不会因登录、退出或注销而删除，也不会在本模块静默合并。
- 客户端账号会话保存在加密的本地关系型数据库中，数据库版本由 2 升级为 3。
- 服务端提供 `/v1/auth/code/request`、`/v1/auth/code/verify`、`/v1/auth/refresh`、`/v1/auth/logout` 和 `/v1/account`。
- 服务端采用 NestJS、PostgreSQL、Redis 和可替换 SMTP 邮件适配器，本地邮件由 Mailpit 接收。
- `users.password_hash` 允许为空，只为后续密码登录保留结构，本模块不提供密码入口。

## 安全规则

- 验证码为 6 位数字，有效期 10 分钟，只能使用一次，并绑定申请设备。
- 每个验证码最多尝试 5 次；申请和验证按邮箱、IP、设备分别限流。
- 数据库仅保存验证码 HMAC，不保存验证码明文；Redis 限流键只包含加盐指纹。
- 访问令牌有效 15 分钟，刷新令牌有效 30 天；每次刷新都会轮换刷新令牌。
- 已轮换刷新令牌再次出现时，服务端撤销同一令牌族，阻止重放。
- 账号注销会删除账号、刷新令牌以及该邮箱残留的验证码记录。
- 邮箱、验证码和令牌不进入普通应用日志。

## 本地联调步骤

1. 在 `server` 目录将 `.env.example` 复制为 `.env`，替换三个开发密钥；服务启动时会自动加载该文件。
2. 安装 Docker Desktop 后执行 `docker compose up -d`，启动 PostgreSQL、Redis 和 Mailpit。
3. 执行 `npm install`、`npm run build`、`npm test` 和 `npm run start:dev`；服务启动后可用 `npm run test:e2e` 复验完整账号链路。
4. 浏览器访问 `http://127.0.0.1:8025` 查看 Mailpit 测试邮件。
5. 手机模拟器执行 `hdc rport tcp:3000 tcp:3000` 后可继续使用客户端默认的 `http://127.0.0.1:3000/v1`；真机需把 `AuthEndpoint.ets` 中的开发地址替换为电脑局域网地址，并保证端口可访问。
6. 打开应用“我的”，依次验证：游客状态、获取验证码、错误验证码、正确登录、退出登录、再次登录和注销账号。
7. 每次操作后检查任务、专注记录和积分，确认游客数据始终保留。

## 本轮实测结果

- PostgreSQL、Redis 和 Mailpit 容器均通过健康检查，数据库迁移和 `/v1/health` 正常。
- 服务端编译和 lint 通过，12 项单元与安全测试通过，运行时依赖安全审计无已知漏洞。
- `npm run test:e2e` 已通过真实数据库、Redis 和 SMTP/Mailpit 验证，包括邮件验证码、登录、刷新令牌轮换、旧令牌重放拦截、退出和账号注销。
- HarmonyOS API 26 手机模拟器已完成真实验证码登录、加密会话重启恢复、退出登录和账号注销；游客档案在退出及注销后仍保留。
- 模拟器实测发现并修复了底部导航被页面内容挤出可视区域的问题；真实服务不可用时也能给出明确错误且不会崩溃。

## 当前限制

- 当前可用平板模拟器仅支持 API 24，低于项目要求的 API 26；按产品决定，1.0 以手机端完成本模块验收，平板账号页面最终适配延期到 1.1，工程不为测试下调最低 API 版本。
- 当前 SMTP 为本地 Mailpit；正式邮件供应商、正式域名、HTTPS 和生产凭据仍需在部署时配置。
- `http://127.0.0.1:3000/v1` 仅是本地开发默认值，真机联调和发布前必须替换为 HTTPS 正式域名。
