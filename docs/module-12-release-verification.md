## 已实现

- Release 启用顶层名称与文件名混淆、代码压缩和日志移除，并生成 name cache 与 source map。
- Release 的 `debug` 标记为 false；正式服务未配置时使用 `.invalid` HTTPS 安全占位地址，不会连接本机 HTTP 或误传用户数据。
- 正式包仅声明网络和代理提醒权限；关闭通用系统备份恢复，数据库保持 S2 加密。
- “我的”页新增数据与隐私卡片，支持导出当前档案 JSON、查看可滚动的隐私政策与用户协议。
- 数据导出仅允许专注配置设置项，排除访问令牌、刷新令牌、随机设备标识和一次性接续令牌。
- 游客可从账号卡片删除本机档案；账号注销成功后，同时清除服务端账号和本机账号档案。
- 服务端生产模式拒绝回环地址、明文 Redis、未启用数据库 TLS、未加密 SMTP、占位发件域名和缺失生产密钥，并按反向代理跳数解析真实客户端 IP。
- 已提供隐私政策、用户协议、AppGallery 文案、截图清单和上架操作清单。
