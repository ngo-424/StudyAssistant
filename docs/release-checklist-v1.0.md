## 代码内发布保护

- Release 已启用源码混淆、文件名混淆、压缩和日志移除。
- 数据库使用 S2 安全等级并启用加密。
- 系统备份恢复已关闭，避免账号令牌和学习档案进入通用备份。
- 权限仅保留网络与代理提醒；不申请位置、通讯录、相机、麦克风或全局悬浮窗。
- Release 使用 HTTPS 安全占位域名；未配置正式服务时账号功能明确不可用，游客功能不受影响。
- 数据导出使用设置项白名单，排除访问令牌、刷新令牌、随机设备标识和一次性接续令牌。
- 账号注销成功后同时清除服务端账号和本机账号档案。

## 上架前必须由开发者完成

1. 在 AppGallery Connect 创建包名完全一致的 HarmonyOS 应用。
2. 确认应用名称“时芽”可用，填写教育类应用信息和本清单配套文案。
3. 部署中国大陆生产服务，配置 HTTPS、PostgreSQL、Redis、SMTP、三个独立强密钥和备份策略。
4. 将 `AuthEndpoint.ets` 的 `PRODUCTION_API_BASE_URL` 替换为正式 HTTPS `/v1` 地址，复验验证码、同步、注销和接续 E2E。
5. 在托管隐私政策中补充实际云服务商、邮件供应商、服务器位置和数据保存期限，并与应用内政策保持一致。
6. 提交代理提醒开放能力申请；获批并打开能力开关后，重新生成 Profile。
7. 使用 AppGallery Connect 云管理签名或发布证书/Profile 生成正式签名包。证书、私钥、密码与 Profile 不提交 Git。
8. 上传 HAP 后检查自动解析的名称、包名、版本、设备范围和权限清单。
9. 上传无个人信息的手机截图、1024×1024 商店图标、隐私政策及用户协议。
10. 完成隐私检测、安全检测、兼容性测试和人工回归后再提交审核。

- 正式签名、能力审批、备案域名、邮件服务和生产凭据均属于外部发布条件，不能写入公共仓库。
