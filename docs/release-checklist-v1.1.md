## 1.1 发布保护

- Release 启用源码与文件名混淆、压缩和日志移除。
- 数据库使用 S2 安全等级并启用加密，系统通用备份恢复关闭。
- 权限仅包含网络、代理提醒和振动；振动只用于操作反馈，不读取或上传数据。
- 数据导出排除访问令牌、刷新令牌、随机设备标识和一次性接续令牌。
- 同步冲突不展示内部标识；载荷无法解析时禁止覆盖，正常选择需要二次确认。
- 1.1.1 接续保持 protocol v1，可识别 `1.0.0 / 1000000` 与 `1.1.x` 目标版本。
- 奖励、积分、成就与结算规则冻结，电子宠物打卡机制延后至 1.2。
