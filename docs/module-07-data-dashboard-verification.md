# 模块 7 数据看板验收清单

数据看板只读取本地专注会话、类别和奖励事件，并在页面打开时重新聚合，不保存重复的汇总计数。

## 数据口径

- 今日专注：仅统计专注阶段的实际 `focusedSeconds`，完整、中断和放弃记录均保留实际用时，休息阶段不计入。
- 今日完成轮次：仅统计结果为完成的专注阶段。
- 连续天数：每个本地自然日至少有一个完整专注轮次；今天尚未完成时，昨天仍可保持当前连续天数。
- 积分：只读取已经存在的奖励事件；模块 7 不提前创建奖励。
- 跨零点会话：按照会话在各自然日的时间占比分摊实际专注秒数。
- 已删除类别：历史记录继续显示原类别名称、删除标记和原颜色；无法识别的类别归入固定中性色“未分类”。

## 手机与平板

1. 打开“数据”入口，确认加载状态后显示四项核心数据。
2. 手机布局应显示两行、每行两张指标卡；平板宽屏应显示单行四张指标卡。
3. 有专注数据时依次显示 7 日类别色堆叠趋势、12 周热力图和类别时间分布。
4. 无专注数据时显示明确空状态，不出现无意义的空图表。
5. 深色模式、大字体和横竖屏下确认指标不溢出，页面可纵向滚动。

## 数据场景

1. 完成一次自由专注，确认今日分钟数和完成轮次增加，类别分布显示“未分类”。
2. 提前结束或放弃一次专注，确认实际用时增加但完成轮次不增加。
3. 完成休息阶段，确认专注时间不增加。
4. 为不同类别分别完成专注，确认 7 日趋势和类别分布沿用类别颜色。
5. 删除一个已有历史记录的类别，确认历史分布仍显示该类别并标记“已删除”。
6. 在 23:59 前开始、零点后结束，确认两个自然日均获得对应时长。
7. 连续多日每天至少完成一轮，确认连续天数正确；中间缺失一天后重新从 1 开始。
