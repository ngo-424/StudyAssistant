# 模块 06：手机窗口、系统体验与轻触感 1.1 验证记录

## 调整范围

- 新增无异常抛出的轻触感服务；无振动器或调用失败时静默退化。
- 开始专注、阶段完成、保存成功与危险操作成功时提供轻触感。
- 增加振动权限，能力仅用于操作反馈。
- 专注页仅在需要处理时展示系统通知、提醒和跨设备状态。
- 手机普通、紧凑、分屏与浮窗继续使用统一的响应式导航。

## 可访问性基线

- 主要操作触控高度不小于 48vp。
- 图标使用系统 Symbol，并用文字或形状补充状态含义。
- 关键文本允许字体缩放，状态不只依赖颜色传达。
