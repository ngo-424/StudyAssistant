# 时芽

时芽是一个面向 HarmonyOS 手机和平板的本地优先专注计时工具。

当前重构阶段已经建立四个一级入口：专注、数据、任务和我的。客户端采用页面、功能状态、领域逻辑和数据访问分层，后续模块将在这一骨架上逐步加入本地数据、专注计时、统计、奖励与跨设备能力。

本地数据使用加密关系型数据库，表结构通过显式版本迁移维护。旧 Demo 的 `study_data.json` 会在首次升级时以事务方式导入可识别任务；旧汇总专注分钟不会进入奖励或统计，原始文件不会因迁移而删除。

任务模块支持创建、编辑、完成、恢复和移入回收站，并可设置备注、预计时长、截止日期和任务类别。类别颜色保存在 `colorSeed` 中，支持可读性预设与 `#RRGGBB` 自定义颜色；界面会根据背景色自动选择高对比度文字。游客产生的任务和类别仅保存在本机数据中。

专注计时核心使用开始时间、截止时间和暂停快照计算剩余时间，不依赖逐秒累加。进行中的计时会保存在本地设置表中，可在进程重新启动后恢复；完整、提前结束和放弃的阶段会以稳定的会话标识安全写入专注记录。默认配置为 25 分钟专注、5 分钟短休息、每四轮一次 15 分钟长休息。

## 工程结构

- `app`：应用初始化和一级导航状态。
- `core`：设计令牌、日志、错误等公共能力。
- `features`：按专注、数据、任务和设置拆分的功能模块。
- `domain`：跨页面复用的数据模型与 Repository 接口。
- `data`：数据库、版本迁移、本地 Repository 和旧数据迁移。
- `shared`：跨功能复用的 ArkUI 组件。

开发构建使用项目配置的 HarmonyOS SDK 26 工具链。

模块 9 已加入邮箱验证码注册与登录。账号服务位于 `server`，采用 NestJS、PostgreSQL、Redis 和可替换 SMTP 邮件适配器；客户端会把账号会话保存在现有加密关系型数据库中。当前默认 API 地址仅用于本地开发，正式发布前需替换为 HTTPS 域名和正式邮件供应商。

1.1 正式名称为“时芽”，版本为 `1.1.0 / 1010000`。Release 构建启用源码混淆，“我的”页面整合账号、专注设置、同步、数据与隐私；隐私政策和用户协议使用独立阅读页面。1.1 仅提供邮箱验证码登录，不提供密码入口。完整上架步骤与外部阻断项见 `docs/release-checklist-v1.1.md`。

登录不会静默移动游客任务、专注记录或积分。用户可以明确选择是否复制本机游客数据，并在同步冲突中比较内容和修改时间后再决定保留哪一份。
